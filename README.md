## About me

I build full-stack web applications, with a focus on e-commerce and the services behind the customer experience. My current stack centers on TypeScript, Next.js, React, and Node.js.

My work spans reusable UI components, customer dashboards, server-side operations, and custom commerce modules. I enjoy connecting these pieces into a complete product—from browsing a catalog to managing an order.

## What I work on

- **Frontend development:** Next.js App Router, React components, responsive layouts, and Tailwind CSS.
- **Forms and validation:** React Hook Form and Zod for customer-facing workflows.
- **Backend development:** Node.js and Medusa, with custom APIs, data models, migrations, and workflows.
- **Headless commerce:** Product discovery, carts, checkout, customer accounts, and order management.
- **Integrations:** Sanity content management, PayPal payments, and AWS email and file-storage services.

## Featured project

### [ACCENZY — Headless E-commerce](https://www.accenzy.com/)

My current commerce work combines a Next.js and TypeScript storefront with a Medusa backend and Sanity-managed content.

The project covers:

- Product browsing, search, comparison, wishlists, and checkout.
- Customer accounts, authentication, saved addresses, and order history.
- Custom modules for reviews, restock notifications, and customer support.
- Wallet and gift-card functionality.
- Payment providers, transactional email, and product-content synchronization.

**Core stack:** TypeScript · Next.js · React · Tailwind CSS · Node.js · Medusa · Sanity · PostgreSQL · Redis

## Working approach

I organize code around reusable components and focused modules, use validation at input boundaries, and write tests for integration behavior. I value clear interfaces and code that makes future changes easier to understand.
